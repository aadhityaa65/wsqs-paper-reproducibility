# Data availability and privacy

No observed household survey records, respondent
identifiers, household-level predictions or household
feature vectors are distributed in this repository.

The synthetic demonstration consists of artificial
examples. It is intended to test code execution, not
to reproduce empirical performance.

The empirical analyses require authorized access to
the restricted analytical dataset. Researchers without
that dataset can inspect the implementation, run the
synthetic demonstration and inspect aggregate benchmark
results, but cannot independently refit the original
household-level analyses.

The private source data and historical analytical
records must never be added to the public repository.

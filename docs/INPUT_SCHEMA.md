# Input specification

Feature construction accepts harmonized survey inputs.

The input contains the 22 service-support questions, three
household-context variables, eight stated-priority ratings and
the municipal supply applicability indicator.

The feature manifest documents the exact question identifiers,
source columns, predictor types and original ordinal levels.

Raw survey harmonization and derivation of provider eligibility
are upstream components of the complete reproduction workflow.

The synthetic example demonstrates score construction and
feature preparation. It is not intended to estimate empirical
model performance.
